# Pinterest access inquiry brief — October 26, 2026

Status: preparation only. No inquiry sent, application submitted, partnership
claimed, or Pinterest content collected.

## Verified entry point

[Official developer support](https://developers.pinterest.com/docs/reference/help-and-feedback/)
directs API-access enquiries to Help Center → Pinterest API and Developer Tools →
API Access. This is a routing channel, not a confirmed academic licensing program.
[Developer guidelines](https://policy.pinterest.com/en/developer-guidelines)
require express permission for extraction and ML training/development.

## Proposed request scope

- Applicant context: Kyung Hee University undergraduate; small noncommercial study.
- Research: retrieve different denim products with similar visible color, wash,
  fading and silhouette from a wearing photo. Non-generative vision encoder.
- Ask first whether a licensing/research route exists; request a bounded pilot
  rather than unrestricted access to the whole platform.
- Photo types: mirror outfits, indoor/outdoor scenes, seated/walking poses,
  partial occlusion, varying illumination. Do not restore pre-wear color or wash.
- Seek written permission separately for access/download, garment crops, private
  Kaggle processing, embeddings, fine-tuning, evaluation, retention and deletion.
- Ask which image copyrights and depicted-person rights are covered by the grant,
  and which require independent permission from creators or other parties.
- Clarify publication of aggregate results, example images and weights separately.
  Source images would not be redistributed by default.
- Ask for eligibility, possible fees, review timetable, quotas and an appropriate
  technical contact. No free access, approval or response time is presumed.

Do not use the DSA systemic-risk researcher route for this unrelated clothing
retrieval project. A developer API approval alone is not the requested ML grant.
No account creation, new terms acceptance or personal contact transmission is
part of preparing this brief.
