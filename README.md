연구 상태: 종료·정리(실루엣 적응 계획 종료, 표면 데이터 병목으로 보류)

실루엣은 두 축의 첫 점수가 비동점인 명확한 쌍에서 동결 FashionSigLIP이 16/18로 C 17/18에 한 문항 차이로 근접했다.
표면은 선별 블록의 판정 기준 통과와 별개로, 현 해상도에서 남은 측정 불안정과 데이터 병목으로 보류한다.
범용 모델 대비 성능은 Qwen3.5-9B의 이 입력 형식에서 순서 불일치 71~78%로 비교가 성립하지 않아 미측정이다.

**한계**
- 쉬운 쌍 선별 표본: 기존 양축 점수가 모두 비동점이었던 비교만 포함했다.
- C는 단일 평가자의 약 109분 간격 방향 재판정 참고치다.
- 문항 18개·기준 사진 16개로, 알려진 사진의 작은 표본이다.
- 저해상 중심 자료를 224px 입력으로 비교했으며, 세밀한 워싱 검증과 새 상품 집단 평가는 남아 있다.
- 이 직접 선택 결과를 이전 90쌍의 점수 유도 선호 수치와 직접 비교하지 않는다.

추가 학습·새 실험·새 가설 제안은 별도 요청 전까지 중단한다.
공개 이력 고지: 초기 커밋 이력에 개별 판정이 포함되어 있음. 현재본의 개별 판정은 제거했으며, 공개 이력과 기존 복제본·캐시는 회수하지 않는다.
과정·실행 기록: [보관 문서](docs/archive/).

**교훈**
- 대리 지표 개선을 실제 매칭 품질 개선으로 해석하지 않는다.
- 결합 질문의 라벨만으로 축별 원인을 해석할 수 없다.
- AI가 만든 정답을 AI가 채점한 일치는 사람 품질의 근거가 아니다.
- 학습 전에 평가자의 반복 방향 신뢰성 C를 측정한다.
- 평가 설계·입력 가시성·분모를 먼저 고정한다.
