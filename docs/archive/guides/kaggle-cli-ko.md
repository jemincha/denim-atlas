# Kaggle CLI 연결 안내

확인일: 2026-10-26. 대상: Denim Atlas. 공식 Kaggle CLI 2.2.5 설치 및 버전 출력을 확인했다. jemincha 계정 OAuth 인증과 본인 노트북 5건 목록 조회를 확인했다. 비공개 CPU 수집 및 T4 GPU 학습 완료까지 확인했다.

## 1. 한눈에 이해하기

브라우저를 대신해 명령으로 Kaggle 노트북을 올리고 실행 결과를 받는 공식 도구다. 학습은 Kaggle에서 실행하므로 랩탑에 GPU가 필요하지 않다. 웹 화면 조작이나 GPU 사용량 제한 해제 기능은 아니다.

## 2. 실제 설치 범위

프로젝트 루트의 `.venv`에 PyPI 공식 `kaggle` 패키지를 설치한다. Python 3.12를 사용한다. 브라우저 확장·MCP·새 스킬은 설치하지 않는다. `.venv/`는 기존 Git 제외 규칙에 포함된다. 인증 정보는 프로젝트나 Git에 넣지 않는다.

## 3. 작동 구조

연구 요청 → Codex가 로컬 코드 준비 → Kaggle CLI 인증 → 비공개 노트북 업로드 → Kaggle CPU/GPU 실행 → 상태 조회 → 필요한 보고서 회수 → 다음 실험.

업로드 성공, 실행 요청 접수, 작업 완료, 모델 품질 개선은 각각 별개다. CPU 수집과 GPU 학습도 구분한다.

## 4. 바로 쓰는 방법

아래 명령은 프로젝트 루트의 PowerShell 기준이다.

```powershell
& '.venv/Scripts/kaggle.exe' --version
& '.venv/Scripts/kaggle.exe' auth login
& '.venv/Scripts/kaggle.exe' kernels list --mine --page-size 5
```

로그인·권한 승인은 사용자가 직접 한다. 비밀번호·토큰을 채팅에 붙여 넣지 않는다. OAuth를 사용할 수 없으면 공식 설정 페이지에서 토큰을 직접 발급해 사용자 홈의 `.kaggle/access_token`에 저장하는 대안이 있다. 파일 내용은 출력하지 않는다.

복사할 요청문: “Kaggle 인증 상태를 비공개 노트북 목록 조회로 확인해. 토큰 값은 출력하지 마.”

## 5. Denim Atlas에 적용

실제 확인한 대상은 이 프로젝트 하나다. 관련 없는 프로젝트에 확대 설치하지 않는다.

- 데이터 확보: GLAMI의 공개 배포본에서 데님 후보를 원격 수집한다. 완료 기준은 다운로드 수·중복 수·파일 검증 보고서가 남는 것이다.
- 육안 점검: 대표 이미지 시트를 보고 데님 포함 여부와 해상도·구도·배경을 확인한다. 표본 검토를 전수 검토로 표현하지 않는다.
- 파인튜닝: 기존 Marqo-FashionSigLIP 코드와 실제 확보한 학습 신호를 사용한다. 학습 손실 감소를 미관측 상품 검색 품질 개선으로 해석하지 않는다.

요청문: “연결된 Kaggle에서 GLAMI 데님 후보를 적당량 확보하고 대표 이미지 점검 후 파인튜닝해. 입력·설정·체크포인트·실제 결과를 기록해.”

이어하기: “저장된 Kaggle 실행 상태를 먼저 조회하고 중복 실행 없이 마지막 실패 지점부터 이어가.”

## 6. 기대효과와 한계

노트북/스크립트 업로드, 실행 요청, 상태 조회 및 보고서 회수를 실제 검증했다. GLAMI CPU 수집과 T4 GPU 학습이 완료됐다. GPU 할당·계정 인증 요건·사용량 제한·데이터셋 이용 조건은 유지된다. Kaggle에 올리는 코드와 데이터의 비공개 설정을 확인한다. 원본 이미지와 가중치는 무조건 랩탑에 모두 내려받지 않는다.

## 7. 작은 시험 과제

인증 후 `kernels list --mine --page-size 5`를 실행한다. 성공 기준은 본인 노트북 목록을 인증 오류 없이 받는 것이다. 이 시험은 연결만 검증하며 GPU 학습이나 연구 성능을 검증하지 않는다. 다음으로 비공개 CPU 작업 하나를 실행해 작은 JSON 보고서만 회수한다.

## 8. 관리·복구·출처

작업 명령을 중단해도 원격 작업은 계속될 수 있으므로 상태를 먼저 확인한다. 인증 해제는 `kaggle auth revoke`로 현재 계정의 갱신 토큰을 폐기한다. 명령 존재는 확인했으며 실제 폐기는 실행하지 않았다. 토큰 폐기는 Kaggle 계정 설정에서 사용자가 직접 한다. 업데이트는 같은 가상환경에서 `python -m pip install --upgrade kaggle`로 하고, 버전과 연결 시험을 다시 확인한다. 제거할 때는 다른 연구 자료와 `.venv`를 구분하며 원격 노트북을 자동 삭제하지 않는다.
